# One — סופרים יחד

משחק ספירה רגוע לילדים בני 4, אח קטן של [אלף](https://github.com/net13200/Aleph).
הילד נוגע בכל דבר על המסך וסופר בקול — כל מספר נקשר לחפץ אחד.

**לשחק:** https://net13200.github.io/One/

## מה יש במשחק

כל משחק הוא 6 סבבים (3–5 דקות), ובסופו חגיגה ומדבקה לספר המדבקות.

1. **נוגעים וסופרים** — על המסך מפוזרים כמה תפוחים, ברווזים, כוכבים… כל נגיעה: החפץ קופץ, מקבל מספר, והקול אומר את המספר הבא. נגיעה שנייה באותו חפץ: ״כְּבָר סָפַרְנוּ אוֹתוֹ״. בסוף הקול חוזר על הסכום עם שם העצם: ״יֵשׁ חֲמִשָּׁה תַּפּוּחִים!״.
2. **כמה יש?** — סופרים בנגיעות, ואז בוחרים את התשובה מתוך 3 כרטיסים גדולים (ספרה + נקודות).
3. **תן לי…** — ״תֵּן לִי שָׁלוֹשׁ בָּנָנוֹת״: נוגעים בחפצים כדי להכניס אותם לסל (כל אחד נספר בקול), ולוחצים על ✓ הירוק. נגיעה בחפץ שבסל מוציאה אותו.

**בלי טיימר, בלי ניקוד, בלי ✗ אדום.** טעות ראשונה: צליל רך ורמז (סופרים יחד). טעות שנייה: מראים את התשובה, סופרים יחד וממשיכים.

**קושי:** מתחילים במספרים 1–3. אחרי שלוש תשובות נכונות ברצף הטווח מתרחב (3 → 5 → 7 → 10 → 12 → 15 → 17 → 20), ואם היה צריך להראות את התשובה הוא מצטמצם שוב. מספר מעל ״המספר הגבוה ביותר״ לא מופיע אף פעם. ב״תן לי…״ המספר מוגבל ל־10.

## אזור הורים

לחיצה ארוכה (1.2 שניות) על המנעול בפינה, ואז תרגיל כפל קטן.

- **שפת הספירה:** עברית / English / שתיהן (ברירת מחדל: שתיהן — ״אַחַת… one״). ההוראות והמחמאות תמיד בעברית.
  במצב English הסכום נאמר באנגלית (״five apples!״), וב״תן לי…״ המשפט בעברית מזכיר רק את שם העצם והכמות נאמרת באנגלית.
- **המספר הגבוה ביותר:** 3 / 5 / 10 / 15 / 20 (ברירת מחדל: 5).
- **שם הילד ופנייה** (בּוֹא / בּוֹאִי, סְפֹר / סִפְרִי).
- **קצב דיבור** עם כפתור ״נסו״, ובחירת קול עברי וקול אנגלי (ברירת מחדל: אוטומטי, קול מקומי עדיף).
- **בדיקת קול:** רשימה של כל המשפטים שהמשחק אומר, עם כפתור השמעה לכל אחד.
- **איפוס התקדמות** (ההגדרות נשמרות).

## קול

המשחק משתמש בקולות של הטלפון עצמו (Web Speech API): קול עברי (`he-IL`) וקול אנגלי (`en-US` / `en-GB`). אין הקלטות סינתטיות.
כל הטקסט המדובר נמצא בקובץ אחד — [`js/data.js`](js/data.js) — כדי שיהיה קל לבדוק את הניקוד. לכל משפט יש מפתח קבוע (`num.he.5`, `p.countAgain.m`, `total.he.apple.5`) כדי שאפשר יהיה להחליף אותו בהקלטה בעתיד בלי לשנות קוד.

## הרצה מקומית

אין שלב בנייה — HTML, CSS ו־JavaScript פשוטים.

```sh
npx http-server -p 8080 -c-1
# ואז לפתוח http://localhost:8080
```

בדיקות (Playwright, iPhone 12 Pro, קול מדומה): משחקים סשן שלם במסלול הנכון ובמסלול הטעויות, בודקים את אזור ההורים וטעינה בלי רשת.

```sh
npx http-server -p 8080 -c-1 -s &
node tests/play.cjs
```

## פרסום

כל push ל־`main` מתפרסם ב־GitHub Pages דרך GitHub Actions (`.github/workflows/pages.yml`).
- בפעם הראשונה: Settings ← Pages ← Source: **GitHub Actions**.
- תיקייה חדשה? להוסיף אותה לרשימת ה־`cp` ב־workflow.
- בכל גרסה חדשה להעלות את `CACHE` ב־`sw.js` (`one-v1` → `one-v2`), אחרת טלפונים יישארו עם הגרסה הישנה.

הכול נשמר ב־`localStorage` במכשיר בלבד. אין חשבון, אין שרת, אין אנליטיקס, אין פרסומות.
